Eleições 2026 — Amapá

Apuração da Eleição

Simulação do sistema proporcional brasileiro (quociente eleitoral, quociente partidário e distribuição de sobras) para Deputado Estadual (24 vagas) e Deputado Federal (8 vagas) no Amapá. Envie os votos de cada candidato para calcular automaticamente o quociente, as vagas por partido e a lista de eleitos.

Enviar votação — Deputado Estadual (24 vagas)

CSV com as colunas Nome,Partido,Votos — uma linha por candidato. Para informar votos de legenda (só no partido, sem candidato), use LEGENDA no lugar do nome. Linhas de brancos/nulos não devem ser incluídas (o cálculo já assume que "Votos" aqui é só voto válido). Coluna opcional Foto com o link direto da imagem mostra a foto do candidato nas tabelas — sem essa coluna, aparece um círculo com as iniciais do nome no lugar.

Importar apoiadores

Envie uma planilha CSV ou Excel com os dados dos apoiadores e importe direto neste painel.

Arquivo de importação

O arquivo deve conter um cabeçalho na primeira linha com os campos que deseja importar. Cada linha precisa ter o nome e pelo menos email ou whatsapp. Os campos suportados são: nome, email, telefone, whatsapp, gênero, data de nascimento, status, nível de confiança, CEP, rua, número, bairro, cidade, estado, complemento, zona eleitoral, seção eleitoral, estudante, trabalhador, profissão, relação, notas, segmentos, convidado por e consentimento.

Use ; ou , como separador no CSV. Arquivos Excel exigem internet para serem lidos.

Arquivos aceitos

Solte quantos arquivos quiser de uma vez — o tipo de cada um é identificado automaticamente pelo conteúdo, não precisa organizar ou nomear nada. Esta é a única tela de importação do painel: os outros relatórios (Painel Geral, Explorar por Região, Buscar Líder, Performance) só leem os dados, não têm upload próprio.

  • campaign_summary*.csv — resumo geral (total de apoiadores, eventos, meta) → alimenta o Painel Geral
  • supporters_by_region*.csv — apoiadores por bairro/cidade/zona → alimenta o Explorar por Região
  • hierarquia.csv — árvore de líderes e quem indicou quem → alimenta Buscar Líder e Performance de Liderança
  • leader_performance*.csv — convidados, confirmados, meta de cada líder → alimenta Buscar Líder e Performance de Liderança
  • engajamento-team*.csv — engajamento de líderes/coordenadores → alimenta Buscar Líder
  • engajamento-por-lider*.csv / engajamento-supporters*.csv — engajamento de apoiadores → alimenta Buscar Líder
  • usuarios_e_seus_apoiadores*.csv — status de confirmação por apoiador (Confirmado/Pendente) e contato do líder → alimenta Buscar Líder. Pode soltar vários de uma vez (ex: um por equipe/segmento) — o sistema une tudo automaticamente, sem precisar unir na mão antes.
Enviar todos os CSVs de uma vez Clique ou arraste — até os 6 tipos de arquivo listados acima, juntos ou separados.

Banco de dados

Envia os relatórios que estão carregados neste painel (líderes, apoiadores, hierarquia e performance) para o banco. Só o administrador pode fazer isso. Depois disso, o arquivo publicado no GitHub não precisa mais conter esses dados.

Ferramenta de conversão

Conversor PDF → CSV

Extrai os dados direto do PDF, no navegador (sem enviar o arquivo pra fora) — a mesma lógica usada nas atualizações anteriores. Pode soltar vários PDFs de uma vez (ex: um por segmento); o sistema une tudo automaticamente. No final, você pode baixar o CSV gerado, ou aplicar direto no painel (mesma base usada em Buscar Líder e Performance).

PDF "Usuários e seus apoiadores"

O relatório com cada líder (telefone, e-mail, bairro, segmento) seguido da lista de apoiadores dele (status Confirmado/Pendente). Pode ser um PDF por equipe/segmento — solte todos juntos.
